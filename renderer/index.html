        Auto-save .drp

        Exports the open project (local or network library) at a fixed interval, and keeps a copy only when the project has changed.

        Save locations

        Each editor can choose their own. Every location gets its own copy; if one is offline (e.g. NAS) the others still save and it catches up later. PC folder is on for network drives (so several PCs don't mix) and off for local disks. The grey line shows where files will go.

        Encoder

        Convert any video with your Resolve presets, built-in or custom, like Media Encoder. Each group has one preset and output folder; any file can use its own instead. Drop files onto a group to add them there, or anywhere else on this page to start a new group. Each file keeps its own frame rate and size; temporary items in Resolve are removed afterwards.
